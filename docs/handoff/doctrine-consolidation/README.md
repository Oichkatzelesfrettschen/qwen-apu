# Doctrine consolidation

`AGENTS.md` moved from 192,995 to 44,624 characters: every mechanism
narrative now lives whole under `docs/doctrine/` and `docs/operations/`,
and the root file keeps rules, gotchas, and pointers. The three frozen
doctrine copies under `docs/split-plan/shared/` are renamed
`DOCTRINE-SNAPSHOT.md` so a session working there loads the live rules
alone.

This directory retains what the consolidation replaced outside git:
`retired-memories/` holds the thirty-eight agent memory files as they stood
before they merged into five, `retired-global-agent-guide.md` holds the
workstation-wide agent guide before it absorbed the system rules those
memories carried, and `memory-harvest.txt` is the fact-by-fact extraction
the merge was performed from. Private hostnames read `qwen-laptop` and the
home prefix reads `$HOME`, the rule every retained evidence file follows.
